# ⚡ DTrongVIP 3D Interactive Cybernetic Space

Live 3D interactive portfolio of **Đào Hữu Trọng (DTrongVIP)** — Artificial Intelligence Student @ Can Tho University (CTU - K52).

🔗 **Live Experience**: [https://daohuutrong2404.github.io](https://daohuutrong2404.github.io)

## 🎮 3D Features
- **360° Free Orbit Rotation**: Drag mouse or swipe touch screen to rotate in 3D.
- **Interactive Orbiting Cubes**: Hover over cubes to scale up and chime; click to inspect details about Autonomous Agents, Deep Learning, and C++ Algorithms.
- **PBR Crystalline AI Core**: Refractive glass icosahedron with golden rotating circuitry.
- **Procedural Sound Engine**: Zero-asset high-tech sound synthesizer built with Web Audio API.
